# LibraryManagementSystem


## About the Project

The **Library Management System** is a console-based application developed using C++. It helps manage library activities such as adding books, registering students, searching for books, and issuing and returning books. It provides separate sections for Admin and Students to make library management easier and more organised.

## Features

- Admin login with password authentication.
- Add, display, search, update and delete book records.
- Register and display student records.
- View available books.
- Issue books to registered students.
- Return previously issued books.
- View issued book records.
- Prevent issuing books that are already issued.
- Store records using file handling.
- Load previously saved records when the program starts.

## How to Run

1. Open the project folder in VS Code.
2. Compile `main.cpp` using a C++ compiler.
3. Run the generated executable.
4. Select an option from the main menu.

### Compilation Command

```bash
g++ main.cpp -o library
```

### Run the Program

**Windows:**
```bash
library.exe
```

**Linux / macOS:**
```bash
./library
```

## Project Files

| File Name | Description |
|---|---|
